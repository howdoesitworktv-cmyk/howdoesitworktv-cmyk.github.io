# Website for TikTok (Terms of Service + Privacy Policy)

1. Replace every `YOUR-EMAIL` in index.html, terms.html and privacy.html with your contact email.
2. Create a free GitHub account (github.com) if you don't have one.
3. New repository > name `pixknowswhy` > Public > Create.
4. "uploading an existing file" > drag in everything in this folder > Commit changes.
5. Settings > Pages > Source "Deploy from a branch" > Branch `main`, folder `/ (root)` > Save. Wait 1 to 2 minutes.
6. Your URLs (replace USERNAME with your GitHub username):
   - Website:          https://USERNAME.github.io/pixknowswhy/
   - Terms of Service: https://USERNAME.github.io/pixknowswhy/terms.html
   - Privacy Policy:   https://USERNAME.github.io/pixknowswhy/privacy.html
7. TikTok app page > URL properties > Verify properties > URL prefix > enter https://USERNAME.github.io/pixknowswhy/
   > Verify > download the signature file > upload it to the same GitHub repository (step 4) > back in TikTok click Verify.
